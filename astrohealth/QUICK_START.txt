ASTROHEALTH 1.1 — WINDOWS / LINUX

Requires Python 3.10 or later. No mandatory pip packages.
Extract the full AstroHealth folder to a permanent location.

CREATE A DESKTOP SHORTCUT (once):
Windows: double-click install_desktop_windows.bat
Linux: run sh install_desktop_linux.sh
Then double-click the AstroHealth desktop shortcut.
Linux may ask you to Allow Launching / Trust and Launch.

OR START DIRECTLY:
Windows: double-click run_windows.bat
Linux: run sh run_linux.sh

The dashboard opens at http://127.0.0.1:8765
Keep the monitor terminal open. Ctrl+C saves and stops the app.
To see simulated readings: Simulation console > Start continuous.
All seven live vital/environment fields are now simulated, including CO2.

MANUAL JSON DEMO REPORTS:
Run python make_demo_reports.py (Linux: python3 make_demo_reports.py).
Import examples/generated/blood_panel_all_supported.json via Import blood test.
Import the dose_*.json files via Import sensor packet. All are synthetic.
Generate reports before starting a live simulation to keep acquisition times in order.
See SIMULATION_COVERAGE.md for remaining manual/unsupported measurements.

Updating an older installation: stop its running monitor first. Keep your data
folder, replace the application files, and restart. Do not delete your database.
D-dimer now requires mg/L; old-unit data stays retained and is not reinterpreted.
