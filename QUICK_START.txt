ASTROHEALTH — MERGED APP

1. Extract the complete AstroHealth folder.
2. Install Python 3.10 or later if needed. No mandatory pip packages.
3. Windows: double-click run_windows.bat
   Linux: sh run_linux.sh
4. Open http://127.0.0.1:8765 for the dashboard.
   The monitor stays running when the browser is closed.
   New warnings open the browser/native warning window.
5. Simulation console: Start continuous or One reading / scenario.
   No data is simulated automatically. Profiles start without current readings.
6. Ctrl+C in the monitor terminal saves summaries and exits.

To open the dashboard at startup:
Windows: py -3 app.py --desktop --open
Linux: python3 app.py --desktop --open

Linux native warning windows may need python3-tk and a graphical desktop.
Browser warning opening remains available without Tk.

Normal raw readings expire after 60 seconds. Daily/session summaries,
abnormal events and manually imported blood tests remain stored.
An abrupt shutdown can lose the unfinished day's normal summary.

See README.md for formats, forecasts, storage rules and limitations.
See VERIFICATION.md for what was actually tested.
